# 🎓 University Admissions Bot

A chatbot designed to assist students with university admission queries by providing concise and accurate information about programs, eligibility criteria, application procedures, and required documents.

## 🚀 Features
- Program eligibility lookup
- Application process guidance
- Document requirements summary
- Quick, compressed responses
- Beginner-friendly chatbot UI

## 🛠 Tech Stack
- Python
- Flask
- HTML/CSS/JavaScript
- JSON-based knowledge base
